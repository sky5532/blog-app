# Blog App

A Twitter-style blog application built with React and Vite.

## Features
- Create a new post
- Display all posts (newest first)
- Like and unlike a post
- Delete your own posts only

## Concepts Used
useState, arrays, .map(), .filter(), event handling, conditional rendering, props

## Run Locally
1. Clone the repo
2. `npm install`
3. `npm run dev`
4. Open http://localhost:5173
